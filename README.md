# Студенческий планер

Мобильное приложение на Android с навигацией между несколькими экранами. Показывает список учебных дисциплин, детали каждой дисциплины, профиль студента, настройки и расписание занятий на неделю

## Экраны приложения

- **Главный экран** - список дисциплин текущего семестра
- **Детали дисциплины** - подробная информация о выбранной дисциплине
- **Профиль студента** - информация о студенте и академическая успеваемость
- **Настройки** - управление уведомлениями и внешним видом приложения
- **Расписание** - расписание занятий на неделю
- **Детали занятия** - подробная информация о конкретном занятии

## Технологии

- Kotlin
- Jetpack Compose
- Navigation Compose 2.7.6
- Material 3

## Схема навигации

```
Главный экран (Home)
├── Дисциплина → Детали дисциплины (Details) → Назад
├── Профиль → Экран профиля (Profile) → Назад
├── Настройки → Экран настроек (Settings) → Назад
└── Расписание → Экран расписания (Schedule)
                  └── Занятие → Детали занятия (ScheduleDetail) → Назад
```
